About the Author

Posted by Santi · Retro web fan

This blog is built as a throwback to mid/late-2000s web design: warm beige panels, rounded corners, side widgets, and clear, readable type.

I wanted something that feels handmade and personal, with the old web personality but modern enough to read on phones and easy enough to host on GitHub Pages.

Site Notes

  • Plain HTML/CSS/JS only.
  • No build tools or framework required.
  • Hardcoded posts rendered from `script.js`.
  • Ready for GitHub Pages deployment.
